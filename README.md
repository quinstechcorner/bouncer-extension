<h1>What's this?</h1>
<p>Bouncer is a safari extension that allows the user to define a list of websites that they wish to be "bounced" from.<br><br>
It acts as a friendly "are you sure" check to break habits - such as attempting to access social media or other sites that the user wishes to stop using.</p>
<h1>How do I use it?</h1>
<p>Sorry to be a pest, but I refuse to pay $99 for an Apple dev license so you'll need to enable unsigned extensions and bypass gatekeeper.</p>

<div class="step-card">
  <ol class="step-list">
    <li>Open <strong>Safari → Settings → Advanced</strong> and check <strong>"Show features for web developers"</strong>.</li>
    <li>In Safari's top menu bar, click <strong>Develop → Allow Unsigned Extensions</strong>.</li>
    <li>Enter your Mac password when prompted.</li>
    <li>When launching the app, macOS will throw a warning, go to the gatekeeper section of System Settings and allow the app to launch.</li>
  </ol>
</div>


<p>Once the app is launched It will then prompt you to access the settings in safari.<br>You will notice the little HAL icon in your toolbar - define your sites there.<br>You can also temporarily disable the redirect by going into safari's extension preferences.<br>Once the app has launched once it'll run in Safari, you can close it.</p>
